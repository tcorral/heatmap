# Heatmap.Sdk.Wpf

Pre-release WPF capture for the Heatmap Windows SDK: `HeatmapWpfCapture`, `HeatmapWpfRustCaptureBackend`, click/scroll capture, and `AutomationProperties.AutomationId` resolution.

Requires **Heatmap.Sdk** (session API and `heatmap_ffi` native runtimes) and **Heatmap.Sdk.Capture** (transitive dependency).

```powershell
dotnet add package Heatmap.Sdk.Wpf --version 0.1.0-pre1 --source ./artifacts
```

See [Windows SDK docs](../../../../docs/windows-sdk.md) for init and integration.
